This establishes recursive node-tree traversal and stack exhaustion. Source review at Blender commit cd5dc428cce1 finds raw ID addresses in writefile.cc lines 835–840, undo restoration in readfile.cc around read_libblock_undo_restore_at_old_address](https://github.com/blender/blender/blob/cd5dc428cce1/source/blender/blenloader/intern/readfile.cc#L3367-L3390), later library linking in [readfile.cc lines 4620 onward](https://github.com/blender/blender/blob/cd5dc428cce1/source/blender/blenloader/intern/readfile.cc#L4620), full-ID swapping in [lib_id.cc lines 979–993](https://github.com/blender/blender/blob/cd5dc428cce1/source/blender/blenkernel/intern/lib_id.cc#L979-L993), and recursive preview traversal in [node_tree_update.cc` lines 923–934. A freed historical fallback’s address could be reused by a temporary parent ID, then cause a restored child pointer to map to that parent itself. The diagnosis must not be presented as a captured collision or a new hue authoring failure.

Each statistic is computed per fixture × exposure × workload, then the worst case is taken. Percentiles are not pooled across fixtures. The predeclared balanced objective minimizes the largest ratio to the previous grid across ten terms: four worst per-case rendered p99 ΔE_ITP values, three absolute scene-RGB p99 values and three absolute scene-RGB RMS values. All terms have equal standing in this minimax rule; a ratio above one identifies a regression. Ties use the worst rendered p99 and then the grid name. The rule requires a nonzero baseline error, so an identity-only grade is unsuitable for this ratio objective.
